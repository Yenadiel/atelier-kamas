ATELIER KAMAS - appli Windows perso
===================================

INSTALLATION (une seule fois, environ 2 minutes)
1. Decompresse ce dossier n'importe ou (clic droit > Extraire tout).
2. Double-clique "Installer Atelier Kamas.bat".
   - Si Windows affiche "Windows a protege votre ordinateur" :
     "Informations complementaires" puis "Executer quand meme".
   - Le script telecharge le moteur Electron depuis GitHub (115 Mo, verifie
     par empreinte SHA256), installe l'appli dans
     %LOCALAPPDATA%\Programs\Atelier Kamas et cree un raccourci sur le Bureau.
3. L'appli se lance toute seule a la fin. Tu peux supprimer ce dossier ensuite.

MODE COMPACT PAR-DESSUS DOFUS
- Bouton "Mode compact" en haut, ou Ctrl + Maj + K (meme en jeu).
- Deplace la petite fenetre par sa barre noire, redimensionne par les bords.
- Bouton demi-cercle : transparence 100 / 85 / 70 %.
- C est l appli entiere en petit : onglet "En cours" (etape, crafts, ressources,
  bouton "Etape terminee") + tous les autres onglets.
- Dofus doit etre en mode fenetre ou "fenetre plein ecran".

TES DONNEES
- Enregistrees sur ce PC (prix, stock, progression, familier).
- Boutons "Exporter" / "Importer" en haut : sauvegarde, ou passage
  page web <-> appli.

MISE A JOUR
- Relance "Installer Atelier Kamas.bat" de la nouvelle version :
  tes donnees sont conservees.
